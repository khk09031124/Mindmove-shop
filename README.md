# 숨결샘 공식 쇼핑몰 — 웹페이지 시안

`Mind & Move Lab × 숨결샘` 브랜드 쇼핑몰 시안입니다. PC·모바일 반응형 단일 페이지(HTML/CSS/JS)로, 폴더째 저장한 뒤 `index.html`을 열면 바로 보입니다.

**라이브 주소**: https://khk09031124.github.io/Mindmove-shop/ (저장소 `khk09031124/Mindmove-shop`, GitHub Pages · main / root 배포)

## 폴더 구성

```
mindmove-shop/
├─ index.html            ← 페이지 전체 (스타일 · 상품 데이터 · 동작이 모두 안에 있음)
├─ assets/               ← 웹용 상품 이미지 8장 (1200px JPEG)
│  └─ hi-res/            ← 원본 고해상도 PNG (인쇄·재편집용)
├─ alternates/           ← 히어로 대안 컷 (hero-alt-woman.jpg)
├─ preview-desktop.png   ← PC 1440px 전체 화면 캡처
├─ preview-mobile.png    ← 모바일 390px 전체 화면 캡처
├─ shots/                ← 히어로 · 컬렉션 · 필터 · 상세 모달 · FAQ · 태블릿 캡처
└─ README.md
```

## 여는 방법

- **PC**: 폴더를 그대로 두고 `index.html` 더블클릭 (Chrome·Safari·Edge 모두 동작)
- **휴대폰**: 폴더를 아이폰 파일 앱 등에 저장한 뒤 `index.html` 열기 — 이미지는 상대경로라 `assets/`가 함께 있어야 보입니다.

## 수정하는 곳

### 1) 상품 (이름 · 가격 · 문구 · 이미지)

`index.html` 안 `const PRODUCTS = [` 배열 하나만 고치면 카드·필터·모달이 함께 바뀝니다.

| 필드 | 뜻 | 예 |
|---|---|---|
| `title` | 상품명 | `'색채 타로카드'` |
| `sub` | 한 줄 소개 (모달 상단) | |
| `desc` | 카드에 보이는 설명 | |
| `img` | 썸네일 경로 | `'assets/p6-color-tarot.jpg'` |
| `tag` | 태그 | `'실물 배송'`, `'디지털 PDF'`, `'출시 예정'` |
| `price` / `was` | 오픈 특가 / 정가 (숫자만, 원 단위) | `38000` / `52000` |
| `status` | `'open'`(오픈 특가) · `'soon'`(출시 예정) | 배지와 버튼 문구가 바뀜 |
| `items` | 구성 목록 | 배열 |
| `for` | 추천 대상 | 배열 |
| `point` | 미리보기 포인트 | 문장 |

할인율(%)은 `price`·`was`에서 자동 계산됩니다.

### 2) 실제 판매 링크 연결

지금은 시안이라 결제 버튼이 안내 문구(토스트)만 띄웁니다. 오픈 시 아래 두 곳을 바꾸면 됩니다.

- **스마트스토어 / 크몽**: 스크립트의 `$$('.m-channels [data-ch]')` 부분에서 `toast(...)` 대신 `window.open('실제 링크', '_blank')`
- **구매하기 버튼**: `#mBuy` 클릭 핸들러(`$('#mBuy').addEventListener`)를 상품별 링크로 이동하도록 교체

### 3) 문구 · 색 · 글꼴

- 상단 공지, 히어로 제목, 브랜드 스토리, 오픈 배너, FAQ는 `index.html` 본문에서 바로 수정
- 색상은 맨 위 `:root` 변수(`--paper`, `--olive`, `--clay` …)에서 한 번에 변경
- 글꼴은 Google Fonts `Noto Serif KR`(제목) / `Noto Sans KR`(본문), 오프라인에서는 기기 기본 한글 글꼴로 대체됩니다
