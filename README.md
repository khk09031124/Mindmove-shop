**라이브 주소**: https://khk09031124.github.io/Mindmove-shop/ (저장소 `khk09031124/Mindmove-shop`, GitHub Pages · main / root 배포)

## 폴더 구성

```
mindmove-shop/
├─ index.html            ← 페이지 전체 (스타일 · 상품·과정 데이터 · 동작이 모두 안에 있음)
├─ assets/               ← 웹용 이미지 10장 (상품 7 + 히어로 1 + 자격증 2, JPEG)
│  └─ hi-res/            ← 원본 고해상도 PNG (인쇄·재편집용)
├─ alternates/           ← 히어로 대안 컷 (hero-alt-woman.jpg)
├─ preview-desktop.png   ← PC 1440px 전체 화면 캡처
├─ preview-mobile.png    ← 모바일 390px 전체 화면 캡처
├─ shots/                ← 히어로 · 컬렉션 · 필터 · 상세 모달 · FAQ · 태블릿 캡처
└─ README.md
```

## 여는 방법

- **PC**: 폴더를 그대로 두고 `index.html` 더블클릭 (Chrome·Safari·Edge 모두 동작)
- **휴대폰**: 폴더를 아이폰 파일 앱 등에 저장한 뒤 `index.html` 열기 — 이미지는 상대경로라 `assets/`가 함께 있어야 보입니다.

## 수정하는 곳

### 1) 상품 (이름 · 가격 · 문구 · 이미지)

`index.html` 안 `const PRODUCTS = [` 배열 하나만 고치면 카드·필터·모달이 함께 바뀝니다.

| 필드 | 뜻 | 예 |
|---|---|---|
| `title` | 상품명 | `'색채 타로카드'` |
| `sub` | 한 줄 소개 (모달 상단) | |
| `desc` | 카드에 보이는 설명 | |
| `img` | 썸네일 경로 | `'assets/p6-color-tarot.jpg'` |
| `tag` | 태그 | `'실물 배송'`, `'디지털 PDF'`, `'출시 예정'` |
| `price` / `was` | 오픈 특가 / 정가 (숫자만, 원 단위) | `38000` / `52000` |
| `status` | `'open'`(오픈 특가) · `'soon'`(출시 예정) | 배지와 버튼 문구가 바뀜 |
| `items` | 구성 목록 | 배열 |
| `for` | 추천 대상 | 배열 |
| `point` | 미리보기 포인트 | 문장 |

할인율(%)은 `price`·`was`에서 자동 계산됩니다.
